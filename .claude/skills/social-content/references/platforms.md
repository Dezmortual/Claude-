# Platform rules

| Platform | Hard limit | Sweet spot | Links | Hashtags | Format notes |
|---|---|---|---|---|---|
| X / Twitter | 280 chars/post | 120–220 | in post or last post of thread | 0–1 | Threads: 4–8 posts, number them 1/, hook post stands alone |
| LinkedIn | 3,000 | 700–1,300 | in post (or first comment if the user prefers) | 3–5 at end | First 2 lines show before "…see more"; short paragraphs, line breaks |
| Instagram feed | 2,200 | 300–800 | "link in bio" only | 5–10 at end | Carousel: 6–10 slides, slide 1 = hook, last = CTA; ≤ 20 words per slide |
| Instagram / FB Reels, TikTok, YT Shorts | caption 2,200 (TikTok 4,000) | 15–45 s script | bio / pinned | 3–5 | Script as scenes: visual · on-screen text · voiceover; hook in first 2 s |
| Facebook | 63,206 | 80–250 | in post | 0–2 | Conversational; questions that invite a real answer |
| Threads | 500 | 150–400 | in post | 0–1 topic tag | Casual, opinion-led |
| Pinterest | title 100, description 500 | desc 200–300 | pin links to the page | 0 (use keywords) | Keyword-rich title; vertical 2:3 image brief |

## Hook patterns (rotate — don't reuse within one batch)

1. **Specific outcome** — "How we cut X from 3 hours to 20 minutes."
2. **Contrarian** — "Most people do X. That's why Y."
3. **Mistake** — "The X mistake that costs you Y."
4. **List promise** — "5 things we wish we knew before X."
5. **Story opener** — "Last week a customer asked us…" (only if true)
6. **Direct question to a known pain** — "Still doing X by hand?"
7. **Before / after** — "Before: … After: …"

## Image sizes for visual briefs

- Square post 1080×1080 · Portrait post 1080×1350 · Story/Reel/TikTok 1080×1920
- LinkedIn/X/Facebook link image 1200×627 · Pinterest 1000×1500
