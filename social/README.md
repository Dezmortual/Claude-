# Social content for manywright.com

Drafts land here. Made with:

- `/social-content` — posts for one topic, page or launch, e.g.
  "LinkedIn and Instagram posts for https://manywright.com/about"
- `/content-calendar` — a month of scheduled posts (+ a CSV to import into Buffer, Later, etc.)
- the `social-media-manager` agent — for larger batch jobs

The brand profile all of them use is
`.claude/skills/social-content/references/brand.md`. It fills itself in from
the site on first use; check it and add your "never say" list.
